## 阶段一：启动栈重构（OCRMECL）

- **OCRMECL（Open Cube Runtime Machine Environment Compatibility Layer）**：物理独立的引导兼容层，在 OCBL 之前于两条固件轨上静默执行。唯一共享契约 `interface/boot_handoff.h`。
- **BIOS 轨**（`ocrmecl/bios/`，纯汇编）：El Torito 组合镜像 `[stage1 512B][core][OCBL.BIN]`；core 完成拉平——A20 强开（int15h+0x92 双图案验证）、临时 GDT@0x1000 + 故障存根@0x1100 + 256 门 IDT@0x2000（表位于 0x7C00 以下，搬移后仍存活，关闭历史"继承固件 IVT"窗口）、8259A 重映射+全掩蔽、unreal-mode IOAPIC 全 RTE 掩蔽、PIC EOI/PS2 排空/DMA 掩蔽，随后前向搬移内嵌 OCBL.BIN 至 0x7C00 并按 El Torito 契约移交（DL 透传，OCBL 零改动）。
- **UEFI 轨**（`ocrmecl/efi/`，独立 PE）：执行引导的全部固件调用（连接扫描、整盘 ISO 读入内存、OCBL.EFI 从缓冲 LoadImage、GOP 800x600x32、RSDP、固定窗口预留、看门狗拆除、GetMemoryMap、ExitBootServices 重试纪律），随后重写 GDT/IDT（自有 64 位表 + 诊断停机存根）、CR3 全树剥离 NX/置 RW（WP 临时关闭绕过固件页表自保护），最后按 MS x64 ABI 跳转 OCBL 的 raw 入口。EBS 之后零固件服务调用。
- **OCBL UEFI 重构为固件无关**：`ocbl_raw.c`（EBS 后入口）、`ocbl_ramdisk.c`（RAM ISO 唯一磁盘后端）、`ocbl_con_efi.c`（帧缓冲控制台+内嵌 8x16 字形+直接 PIT 时钟+串口键盘）、`ocbl_mmap_efi.c`（捕获的 EBS 内存图→E820）；旧固件流程五文件删除。
- **探测器**（`tools/probe/`）：BIOS/UEFI 两个裸机探测镜像 + `qemu_behaviors.sh` 编排，四份原始转储（默认/严格 × BIOS/UEFI）与《QEMU 保姆行为拉平清单》存于 `evidence/.../probe/`。
- **严格矩阵**（`make test-strict`）：`-cpu qemu64,enforce -machine vmport=off -boot strict=on` 下双轨全链 OCRMECL→OCBL→内核→ush **双绿**。

## 阶段二：i18n 与编码体系

- **资源表**（`ocos/interface/i18n_res.h` + `ocos/kernel/core_i18n_res.c`）：51 条系统消息的 `lang_en`/`lang_zh` 表 + `get_text(MSG_ID)`（zh→en→"?"回退）；追加式扩展协议与构建期尺寸断言。
- **L1 通道**：L1SVC op 18（`get_text`）+ op 19（`serial-probe`）；`ocos/interface/i18n.h` 的 L1 助手。
- **迁移**：L0 内核/异常/用户态 ELF/更新流程 24 处 + 18 个零翻译 L1 应用 51 键 + ush 高频"未找到命令"；机器契约锚点清单 `tools/i18n_contract_anchor.txt`（14 条永英文行）。
- **启动恢复**：`shell.lang` 与 `serial.encoding` 开机读回（旧流程只写不读——中文用户每次重启回英文，勘案发现）。
- **serial-probe 向导**：两种编码样例裸发 COM1 由用户肉眼确认后写入 `/etc/opencube.conf` 并持久化。
- **update.json 双语**：`description: {en, zh}` 新结构（`changes` 扁平键保留兼容旧内核）；内核 v2 链路与网页端均已适配。
- **抽查**：`evidence/.../i18n-samples/zh-20-samples.md`——中文环境 20 条报错与提示 **100% 中文**。
