## 4.2 VMware 三重故障的结构性修复（F1–F4，禁补丁禁特判）

- **F1 串口轮询全链超时**：OCRMECL stage1/core、OCBL stage1、`ocbl_serial`
  的 THR-empty 无超时死循环全部加自旋预算——VMware 下 LSR 位不置位不再挂死。
- **F2 COM1 SCR 探测**：双图案写读回判别真实 16550（VMware COM1 行为差异容错）。
- **F3 VGA 进度标记**：引导链各阶段向 VGA 文本行写标记（R/B/F/A/G/P/I/L/M/S），
  死点直接暴露在屏幕上（标记在 VBE 模式切换后清除，为诊断设计）。
- **F4 EFER 标准化清零**：handoff32 显式清 IA32_EFER（ ecx 保存——修复了 MSR
  序列覆盖 rcx 的入口跳飞 bug）。
- 修复过程中三个 live-caught bug（QEMU 实测发现）：EFER 清零覆盖内核入口 →
  jmp ecx 跳飞；VGA 标记 pop es 破坏 unreal-mode flat ES → OCBL stage1 执行错位；
  vga_mark bh 残留 0xB8 → 写飞 0xC470x。全部修复并回归。
