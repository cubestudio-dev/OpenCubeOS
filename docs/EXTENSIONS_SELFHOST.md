# WP-10c-selfhost — rule-9 system self-sufficiency interfaces

Batch goal: every OS feature must be fully usable **from inside the
oc> shell** — no host tools, no host scripts, no QEMU tricks.  The
rule-9 audit found three gaps: creating an A/B update disk
(`tools/make_ab_disk.sh`), installing the OS to a disk (nothing), and
installing the GRUB boot loader (host `grub-mkrescue`).  This batch
closes all three with in-system commands and the plumbing they need.

## New shell commands (kernel/disk_setup.c)

```sh
abdisk <dev>        # A/B update disk: MBR p1..p4 (64M boot/flags,
                    # 128M slot A, 128M slot B, 128M data), FAT32,
                    # /boot/grub/grub.cfg (slot selection), the booting
                    # kernel seeded into slot A, GRUB BIOS boot loader
                    # (MBR gap).  Re-runs the A/B framework scan, so
                    # update --status works immediately.
install <dev>       # single-system install: MBR p1 (whole disk),
                    # FAT32, /boot/opencube.elf + /boot/grub/grub.cfg,
                    # GRUB BIOS boot loader.
grub-install <dev>  # write only the GRUB BIOS boot loader onto an
                    # already-partitioned disk: boot.img -> LBA0 (with
                    # the core-start LBA patched at 0x5C and the on-disk
                    # disk signature + partition table preserved),
                    # core.img -> the MBR gap (LBA 1..) or, on GPT
                    # disks, the BIOS boot partition
                    # (21686148-6449-6E6F-744E-656564454649).
abcfg               # print the grub.cfg files abdisk/install write.
```

## L1 extension interfaces

### kernel/part.h

```c
int  part_register_child(const char *parent_name, int parent_idx,
                         int part_no, u64 start_lba, u64 sectors);
     /* Register partition <parent>pN as its own block device that
      * forwards sector I/O to the parent with a start-LBA offset.
      * Returns the device index (>= 0), the existing index when the
      * name is taken, -1 on error. */

int  part_write_mbr_table(int dev_idx, const u8 types[4],
                          const u32 starts[4], const u32 sectors4[4]);
     /* Write a classic MBR partition table (4 entries, 0xAA55). */

void part_scan_register_all(void);
     /* Boot-time scan: register "<disk>pN" child devices for every
      * partition of every block device (MBR or GPT).  Runs before the
      * A/B scan so single-system install disks are mountable after a
      * reboot.  Idempotent. */
```

### kernel/ab_update.h

```c
int oc_ab_rescan(void);
     /* Re-run the A/B disk discovery at runtime (after abdisk created
      * the layout; the boot-time scan is one-shot).  Best-effort umount
      * of /ab/*, then a fresh discovery + mount. */
```

### kernel/multiboot2.h

```c
int oc_mb2_get_kernel_self(const u8 **data, u64 *size);
     /* The booting kernel ELF attached by the bootloader.  The ISO and
      * disk grub.cfg files carry `module2 /boot/opencube.elf self`, so
      * the payload always travels with the boot media (mainstream
      * installer pattern) and install/abdisk copy exactly what is
      * running.  Returns -1 when the bootloader attached no "self"
      * module.  The module's physical pages are reserved at boot. */
```

### kernel/grub_boot_data.h (build-time generated)

```c
extern const unsigned char oc_grub_boot_img[];   /* 512 B, i386-pc */
extern const unsigned char oc_grub_core_img[];   /* grub-mkimage output */
extern const unsigned int  oc_grub_boot_img_len;

```

## Behavior notes

- **Cluster sizing**: mkfs.fat32 now picks the cluster size from
  Microsoft's standard FAT32 table (512 B up to 260 MiB, 4 KiB up to
  8 GiB, ...) instead of hardcoding 1 sector/cluster.  A 512 MiB volume
  now formats AND mounts (the mount-time FAT cache kmalloc used to fail
  on the 4 MiB FAT a 1-sector-cluster volume produced).
- **Boot-time partition scan**: every partition of every disk appears
  as `<disk>pN` right after boot (Linux-style), so `fatmount hdap1 /mnt`
  works on install disks without any A/B layout.
- **Sync before power-off**: writes go through the disk cache;
  `sync` ("disk cache flushed") pushes them out before you remove
  power.  abdisk/install print a reminder to reboot/sync.
- **UEFI machines**: abdisk/install/grub-install write the BIOS boot
  path (GRUB i386-pc).  Boot the installer from the ISO for UEFI
  machines — the ISO itself is BIOS + UEFI bootable.
