Every entry below is extracted from the real tree at generation time: the shell command table from a live help -a runtime capture, the interface declarations straight from the surface headers. Regenerate with make api-docs.

  • Shell commands (runtime authority): 233
  • L1 extension interfaces (numbered surface, the README formula 57+8+13+7+26+11+7+9+8+16): 162
  • Callable declarations across the 13 surface headers (includes internal helpers and unnumbered items): 278
  • Syscalls: 53 (grep -c '#define SYS_' kernel/core/core_syscall.h)
  • Source lines: 140,672 across 353 files (README verification command; .c/.h/.S, generated data blobs excluded)
