Common errors — the high-frequency list ​

The errors you will actually hit, most-frequent first, each as symptom → cause → fix. This is the short list; the complete per-subsystem inventory (with investigation chains) is error-catalog.md; failures that print nothing are silent-failures.md.

Testing gates ​

  • SSH E2E needs the seeded host key (the mtools recipe in ../dev/e2e-suites.md).
  • HTTPS E2E item 0 requires the self-signed chain to be REFUSED — if it connects, check tls.insecure is 0.
  • The regression suite needs pexpect; the SSH suite paramiko.
  • Flaky serial? See silent-failures.md §8 and qemu-debugging.md §errata.
