# 3.0.0-WP06g2 — L1 本地化 + 系统 IME

l1_i18n 批次：Ring-3 世界变成双语的，中文输入成为一项
系统服务。

## 变更内容

- **i18n 框架。** 274 个 Ring-3 程序中的每一个都携带
  `i18n/en.json` + `i18n/zh.json`（文件夹应用在
  `src/L1/<name>/i18n/`，遗留平铺程序在
  `src/L1/_i18n/<name>/` 下）。资源编译成逐应用按键排序的
  表（`gen_userprogs.py`，严格门禁——缺资源即构建失败）；
  `_shared/i18n.h` 提供 `tr_()` 运行时（每进程一次
  `L1SVC DISP/LANG_GET` 探测，zh 缺失回退 en，en 缺失回退
  键名）。L0 侧保留一张共享表
  （`etc/i18n/l0/{en,zh}.json` → `tools/gen_l0_i18n.py`）。
  没有硬编码：源码写 `tr_("key")`，资源文件携带文本。
- **`lang zh` 现在是真的了。** 五条 `lang` 消息的历史 zh 列
  自 v2.2.0 抢救以来一直是英文占位符——它们现在渲染真正的
  中文。`help -a` 为全部 274 个程序显示中文注册表提示；
  shell 内建、文件工具（usage/error 句子）、`stat`、
  `free`、`ps`、`date` 遵循 zh_CN 约定（句子翻译，列骨架
  英文）。
- **系统 IME。** 一个引擎 + 一个会话住在 L0 显示服务里
  （`ime_session.c`）；编辑器经新的
  `L1SVC_DISP_IME_BEGIN/KEY/END` 操作（13/14/15，按编号
  契约追加）驱动它，绝不内嵌副本。候选词组优先
  （622 个手工编写的高频词，池化表），然后是单字（全部
  3755 个一级汉字），再一个智能组词候选（前 2-3 段的
  精确音节切分）。每页九个；PageUp/PageDown（或 `-`/`=`）
  翻页；数字 1-9 选择；空格选第一个；Enter 提交原始字母；
  Esc 清除。`ime -i`（交互式控制台组词行）运行同一个
  引擎。
- **编辑器。** `editor_core.h` 具备 UTF-8 字形感知（按字符
  移动、整字形删除并精确擦除单元格、多字节
  插入），新增 `^K` 剪切 / `^R` 复制 / `^U` 粘贴，F2 切换
  系统 IME（组词条渲染在状态行上）。
  `vi` 真正模态化：同一引擎之上的 CMD 模式（`hjkl`、`x`、
  `dd`、`yy`、`p`、`i/a/o`、`:w/:q/:wq/:q!`）。
- **make-all 缺口关闭。** `userprogs_data.h` 成为真正的 make
  目标（见 KNOWN_ISSUES）；i18n json 文件也进入过期
  集合。

## 途中活捉

词组池没有 NUL 分隔符（生成器数了 +1 却从不追加——整个
词库静默地永远匹配不上）；词组二分查找在长度平局时方向
搞反；智能组词排在真实字符之上；`l1_l1_dispatch` 渲染从不
NUL 终止（每次 `help -a` 的 strlen 都越界跑进堆约 100
字节）；ush 自己的帮助缓冲停在 8 KiB；串口 CSI 表缺少
xterm F 键序列（F2 从真实终端无法到达——原始 0x90..0x9B
不会从串口到达）。

## 验证

i18n 测试组 7/7、IME 测试组 3/3、编辑器测试组 10/10、逐程序
提示测试组 4/4（全部 274 条中文提示逐字节扫描）、WP06g1
回归集（chinesetest 81/81、V4/V4b/V5、字体审计 6763+682）
在最终镜像上全绿。
