1. 构建流水线（17） ​

文件职责
build.shPOSIX 一条命令入口：依赖检测（gcc/ld/nasm/grub-mkimage/xorriso/mformat/mcopy/python3/zip，各自带其 Debian 包）、--install apt 回退、OC_TOOLS 自动发现、目标分派，以及 WP-13 规范 8 可脚本化 API（build_all/build_iso/build_src/build_ota/config_load/config_save/config_get/cache_lookup/cross_compile/cross_toolchain_setup）
build_iso.shOCOS 发布 ISO：把双固件 OCBL 对（BIOS stage1+core + UEFI PE）+ 内核 + ocire.elf 经 OCBL ISO 打包器上架；G13 确定性封印委托给打包器 → build/opencube.iso

make_update_pkg.shOTA 包：manifest.json（版本 + 文件 + 按归档顺序拼接的载荷体 sha256）+ 内核 + etc + 文档；自 WP05 起无 boot-cfg 成员（OCBL 动态扫描）
make_ocos_tar.py确定性 OCOS.TAR 安装载荷（boot/opencube.elf + boot/ocire.elf + etc/opencube.conf；ustar、零 mtime、已排序）
make_ab_disk.shA/B 更新盘 build/abdisk.img：p1 boot/flags 64M FAT32 + slot A 128M + slot B 128M + data 128M；仅 mtools（无 loop、无 root）；预置 slot A
make_ocire_disk.shWP-02 双启动测试盘：hd0 GRUB 双菜单（OCOS 卷 + 恢复条目），hd1 OCIRE 盘（0xEE 影子、无 GPT 头、FAT12：黄金文件 + MANIFEST.TXT SHA-256 + agent + 64 KiB 日志环）

oc_cc.sh内容寻址编译缓存封装：键 = SHA-256（编译器身份 + 参数 + 源哈希 + 来自 -MM 的头文件内容哈希）；命中按字节一致还原 .o+.d（reproducible-check 保持有效）；OC_CACHE_OFF 绕过、OC_CACHE_DIR 迁移、计数器追加到 STATS
oc_menuconfig.sh无依赖的交互式 .config 编辑器（数字=切换，s=保存，q=退出，r=重置）

update_website.sh读 dist 资产 → 写 website/assets/site-data.js + website/update.json + update-v2.json（OTA 清单）；每次发布幂等，无任何手工编辑
