# 3.0.0-WP-l1apps-merge

合并应用发布：200+ 条散落的命令获得了一个按意图驱动的
前门，文档也为这个时代从头重写。

## 8 个合并大应用

`update`、`disk-tool`、`net-tool`、`sound-tool`、`files`、
`sysdiag`、`hwinfo`、`power`——每个应用有三扇门：

- **无参数**——意图向导：单键菜单、
  自动检测、跨域修复（`update` 向导在真正检查更新之前，
  先通过 DHCP 修复缺失的 IP、通过 `lsblk` + `abdisk` 修复
  缺失的 A/B 磁盘），每个破坏性路径上重输 + 裸 y 双重确认，
  完全双语（`lang zh` 实时切换整个向导）。
- **`direct <op> [args]`**——显式逐字透传。
- **`<op> [args]`**——经典分发：历史
  命令拼写，逐字节一致的输出。

零功能损失：全部 276 条历史命令保持
注册（接口冻结；回归门禁强制下限）——程序注册表现在计数
**284 个程序**（+ 12 个 ush 内建 = 296 条命令）。

## 交付了什么

- `ocos/interface/wizard_lib.h`——共享的向导原语
  （L1SVC 捕获、锚点探测、READLINE 询问、单键菜单、
  y/N 确认）。
- `ocos/l1apps/` 下的 8 个应用文件夹（update 原地替换）+
  每个应用的双语 i18n 资源。
- `help -w` 增加领头的 **mega** 组（8 个应用），以及它的
  l0 i18n 键。
- update 向导的 5 步链：网络 -> A/B 磁盘 -> DNS
  （主机名从活动的 `config get update_url` 解析）-> 检查
  （已是最新则 OK 退出）-> 确认安装 + 确认重启。
- 受防护的破坏性路径：mkfs.*、abdisk、install、rm、电源
  动作（仅向导——经典/direct 为脚本保持逐字）。

## 兼容性

- 每个历史命令名仍可解析（冻结已强制执行）。
- 无参数的 `update` 现在打开向导；历史上的
  裸 `update` 在线流程是 `update direct`（或任何参数
  形态，与从前逐字一致）。
- 服务输出行未变——向导与脚本探测的英文
  锚点（`"A/B disk: present"`、`"New version available."`、
  `"DHCP success: IP="`、`"DNS resolution failed"`、
  `"reboot required"`）是契约的一部分。
