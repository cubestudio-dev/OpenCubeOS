# Private headers: the `ocos/interface/` contract

`ocos/interface/` is the **only header set a ring-3 application may
include** - enforced at build time: `tools/gen_userprogs.py`'s
`CFLAGS_BASE` exports exactly this directory on the L1 compile `-I`
path, and nothing under `ocos/kernel`, `ocos/drivers` or
`ocos/services` is ever on an L1 include path. `l1_api_surface.h`
states the rule in its header comment and calls itself "the single
place to audit what L1 can see". Ten files, one ABI. Every name is
NAK `l1_<class>_<role>`: the directory as a whole is the L1-facing
side of the L0 service surface, so the NAK major class is `l1_` for
all ten (the one historical spelling kept is `l1_diag_cmds.h`, which
already complied):

| File | Lines | Class / role |
|---|---|---|
| `l1_api_surface.h` | 42 | api / surface - the umbrella include |
| `l1_api_syscall.h` | 337 | api / syscall - the ring-3 runtime library (header-only) |
| `l1_svc_ops.h` | 261 | svc / ops - the L1SVC protocol constants (auto-generated mirror) |
| `l1_fs_api.h` | 87 | fs / api - VFS on-wire structs + helpers |
| `l1_i18n_api.h` | 162 | i18n / api - per-app bilingual runtime |
| `l1_i18n_res.h` | 128 | i18n / res - the shared MSG_ID message resource |
| `l1_wizard_api.h` | 218 | wizard / api - interactive wizard primitives |
| `l1_editor_core.h` | 810 | editor / core - the shared editor engine |
| `l1_diag_cmds.h` | 234 | diag / cmds - the shared driver/device diag layer |
| `l1_crt_entry.asm` | 36 | crt / entry - shared ring-3 entry trampoline |

The reader-facing companions are [../l1/overview.md](../l1/overview.md),
[../l1/writing-apps.md](../l1/writing-apps.md) and
[../l1/app-anatomy.md](../l1/app-anatomy.md); the syscall side of the
contract is [syscall-ring3.md](syscall-ring3.md).

## `l1_crt_entry.asm` - the ring-3 entry

Kernel `execve` enters a new process with `[rsp]=argc, [rsp+8]=argv[0]..`
- a layout a compiled C `_start` cannot safely read (the compiler
prologue may push before touching `rsp`: the WP04 G5 live-catch). So
every app links this 36-line trampoline once and defines
`int app_main(int argc, char **argv)` instead:

```asm
_start:
    mov  rdi, [rsp]              ; argc
    lea  rsi, [rsp + 8]          ; argv
    and  rsp, -16                ; SysV: align before call
    call app_main
    mov  edi, eax                ; exit code
    mov  eax, 16                 ; SYS_EXIT2
    int  0x80
    hlt
section .note.GNU-stack noalloc noexec nowrite progbits
```

Exit goes through `SYS_EXIT2` (16) - the modern exit that runs the
unified process reaper. The `noexec` GNU-stack note keeps the linker
from demanding an executable stack.

## `l1_svc_ops.h` - the frozen protocol mirror

Generated by `tools/gen_l1svc_ops.py` as a **verbatim mirror** of
`ocos/services/sysapi/interface/svc_sysapi_l1svc.h` (single-line
`#define L1SVC_*` lines only; the `L1SVC_CAT_NAME` function macro is
skipped), and regenerated by `gen_userprogs.py` before building app
folders. Why a mirror: apps must not include kernel-side headers, but
the category/op numbers are an ABI that ring 0 and ring 3 must agree on
byte-for-byte - so the generator copies the single-line constants into
the one legal include directory. The upstream header states the
contract: "Renumber only by appending", and notes that cat 18 is a
verbatim contract with the OCIRE log agent. The 20 categories:

```c
#define L1SVC_CAT_TIME      1   /* services/time    */
#define L1SVC_CAT_BLOCK     2   /* services/block   */
#define L1SVC_CAT_NIC       3   /* services/nic     */
#define L1SVC_CAT_SND       4   /* services/snd     */
#define L1SVC_CAT_POWER     5   /* services/power   */
#define L1SVC_CAT_OTA       6   /* services/ota     */
#define L1SVC_CAT_FS        7   /* services/fs      */
#define L1SVC_CAT_NET       8   /* services/net     */
#define L1SVC_CAT_HEALTH    9   /* services/health  */
#define L1SVC_CAT_KLOG     10   /* services/klog    */
#define L1SVC_CAT_WATCHDOG 11   /* services/watchdog*/
#define L1SVC_CAT_CRYPTO   12   /* services/crypto  */
#define L1SVC_CAT_L1       13   /* services/l1      */
#define L1SVC_CAT_DISPLAY  14   /* services/display */
#define L1SVC_CAT_INPUT    15   /* services/input   */
#define L1SVC_CAT_CAMERA   16   /* services/camera  */
#define L1SVC_CAT_USB      17   /* services/usb      */
#define L1SVC_CAT_OCIRE    18   /* services/ocembed  */
#define L1SVC_CAT_DIAG     19   /* services/diag     */
#define L1SVC_CAT_TUI      20   /* services/tui      */
```

208 op defines follow, one per service operation (full tables:
[syscall-ring3.md](syscall-ring3.md)). Users: every L1 app via
`l1_api_syscall.h`'s `l1svc()` wrapper, and the OCIRE agent (which compiles
against the numbers as an ABI, not an include).

## `l1_api_surface.h` - the umbrella

Includes five of the other eight C headers (`l1_api_syscall.h`,
`l1_svc_ops.h`, `l1_fs_api.h`, `l1_editor_core.h`, `l1_i18n_api.h`).
An app that includes only this one header sees that whole slice of the
legal L1 surface - which is what makes the audit claim above true.
`l1_crt_entry.asm` is linked, not included; `l1_wizard_api.h`,
`l1_diag_cmds.h` and `l1_i18n_res.h` are included directly (or pulled
in transitively by `l1_i18n_api.h`) by the apps that want them.

## `l1_api_syscall.h` - the ring-3 runtime library

Header-only (all `static inline`) - each app compiles its own copy, no
shared user library exists. Exports, in dependency order:

- **Syscall numbers** - the verbatim contract with
  `ocos/services/sysapi/interface/svc_sysapi_syscall.h`: `SYS_WRITE 1`
  ... `SYS_L1SVC 110` (54 numbers; [syscall-ring3.md](syscall-ring3.md)
  has the complete table).
- **Raw syscall helpers**: `syscall0..syscall4` (`int $0x80`, `r10` as
  4th arg) plus `syscall5` - the **`r8` as 5th arg** variant that only
  `SYS_L1SVC` uses.
- **Typed wrappers**: `sys_write/read/open/close/exit2/getpid/l1svc/ getcwd/getch/uptime/meminfo/kill/ps/readdir/mkdir/rmdir/unlink/stat/ symlink/readlink/link/chmod/chown/netcmd`.
- **`l1svc_main(argc, argv, cat, op)`** - the standard wrapper-app body:
  joins `argv[1..]` with spaces into a 256-byte arg, calls
  `sys_l1svc(cat, op, arg, out, 4096)` with a `static char out[32768]`
  (BSS, not stack - the buffer is 32 KiB), prints the result; failure
  prints `"<name>: " tr_("svc_call_failed")`. Most of the 284 apps are
  this wrapper plus one line.
- **Tiny string/IO**: `strlen_ streq_ starts_with_ strcpy_ strcat_ strcmp_ atoi_ puts_ putc_ putu_ putx_`.
- **Fixed-width aliases** (`u64/i64/i32/u32/i8/u8`) and the kernel-ABI
  struct `struct ush_ps_entry {i32 tid; i32 state; i32 priority; char name[32]; u64 cpu_time_ticks;}` (the `SYS_PS` on-wire shape).
- Includes `l1_i18n_api.h` at its tail, so every app gets `tr_()` for free.

## `l1_fs_api.h` - VFS on-wire structs

The structs MUST match the kernel's `vfs.h` byte-for-byte
(`VFS_NAME_LEN=64`; the kernel memcpy's `sizeof(struct)` into the
caller buffer - a mismatch would be silent memory corruption):

```c
#define USH_TYPE_FILE 1
#define USH_TYPE_DIR  2
#define USH_TYPE_DEV  3
struct ush_dirent { char name[64]; int type; u64 inode; };
struct ush_stat  { int type; u64 size; u32 mode; u32 uid; u32 gid; u32 nlink; char name[64]; };
```

Plus the ush-verbatim helpers `strncpy_ strstr_ strncmp_ memset_`.
Users: every file-touching app (`ls`, `files`, the editors' load/save
paths, `disk-tool`).

## `l1_i18n_api.h` - per-app bilingual runtime

Per-app tables are generated into each app's `i18n_gen.c`
(`I18N_EN[]/I18N_ZH[]`, key-sorted `struct i18n_kv`), from the app's
`i18n/{en,zh}.json` (the reserved key `"_hint"` is the registry hint
consumed by `gen_userprogs.py`). Two design points:

- **Live locale probe** `i18n_lang_zh()`: a self-contained inline
  `int $0x80` - `SYS_L1SVC(110), cat=L1SVC_CAT_DISPLAY, op=L1SVC_DISP_LANG_GET, arg=0, out=&buf, cap=8`; true when `out`
  starts `"zh"`. Probed per `tr_()` call with **no static cache** (the
  #136 fix, so `lang zh` takes effect immediately in long-running
  apps).
- **`tr_(key)` miss policy**: zh table when locale is zh (miss -> en),
  en otherwise, miss -> the key itself. "An untranslated app can never
  crash or print garbage."

Users: every app, including the 8 mega-apps (their shared wizard keys
`wiz_quit`/`wiz_select`/`wiz_pause`/`wiz_svc_failed` flow through this
runtime). The L0-side counterpart (kernel services' own i18n) is
`core_lib_i18n.c` + `etc/i18n/l0/*.json` - a different mechanism, see
[chinese-layer.md](chinese-layer.md).

## `l1_i18n_res.h` - the shared message resource

The `MSG_ID` enumeration (`msg_id_t`, ending in `MSG_ID_COUNT`) that is
the single shared numbering for the system message tables: the kernel
side `ocos/kernel/core_i18n_res.c` fills `lang_en[]`/`lang_zh[]` with
`get_text(MSG_ID)`, and the L1 side reaches the same ids through
`l1_i18n_api.h` (`tr_()` and the L1SVC op the header wraps). One
enumeration for both rings means an id can never drift between the
kernel table and an app lookup; the additive-extension contract and the
build-time size assertion live in the two tables' headers.

## `l1_wizard_api.h` - wizard primitives + the anchor contract

Used by the 8 merged mega-apps (`update`, `disk-tool`, `net-tool`,
`sound-tool`, `files`, `sysdiag`, `hwinfo`, `power`). Contract: the
caller owns a `WIZ_OUT_CAP 32768` static BSS output buffer; line input
via `SYS_READLINE`; single-key picks via non-blocking `SYS_GETCH`
(digits 1..9, q/Q/ESC abort); all human strings through `tr_()`.

The load-bearing idea is the **anchor mechanism**: wizards parse the
services' own English output lines as the stable contract -
`wiz_find(hay, needle)` (substring probe) and
`wiz_token_after(hay, key, dst, cap)` (first whitespace-delimited
token following `key` - `"IP: 10.0.2.15"` + `"IP:"` -> `"10.0.2.15"`).
No structured API was invented; the rendered text IS the interface.

Full primitive list: `wiz_svc` / `wiz_svc_quiet` (run one L1SVC op,
print or stay silent), `wiz_ask` (blocking line),
`wiz_confirm` (ONLY a bare y/Y answers yes), `wiz_pause`,
`wiz_menu` (numeric single-key picker, items are i18n keys),
`wiz_banner`, `wiz_step(step,total,what)`, `wiz_ok` / `wiz_fail`
(`"[OK] <s>"` / `"[!!] <s>"`). The OCSE-side counterpart (its own
wizard over its own command surface) is `ocse/ocse_wzctl.c` - same
pattern, different world. Tutorial: [../l1/wizard-library.md](../l1/wizard-library.md).

## `l1_editor_core.h` - the shared editor engine

810 lines of nano-style engine included (not linked) by **nano**,
**vi** (under its modal layer) and **edit** - three commands, one
engine. Key facts:

- Fixed buffers: `UNANO_MAX_LINES 256` x `UNANO_LINE_CAP 128`, one-line
  clipboard, IME strip[160], differential status bar `unano_bar_prev[192]`.
- **BUG #34 guard**: `unano_file_truncated` set on load when the file
  exceeded the limits; `unano_save()` then REFUSES to overwrite
  ("save REFUSED, original file untouched").
- UTF-8 discipline: `u8_is_lead/u8_prev/u8_next/u8_cols` plus the
  wide-range table `k_wide_extra[]` (2E80-2EFF, 3000-303F, 3041-30FF,
  3400-4DBF, 4E00-9FFF, F900-FAFF, FF00-FF60, FFE0-FFE6 -> 2 cells) -
  the same width rules the kernel console applies
  ([chinese-layer.md](chinese-layer.md)).
- Viewport: `ED_VIEW_ROWS 20` at `ED_ROW_BASE 2`, ANSI save/restore
  addressing for the pinned status bar, screen clear on exit.
- **System IME bridge**: F2 (key code 0x91) toggles; every keystroke
  while composing is fed to `unano_ime_feed(key)` -> L1SVC
  `DISPLAY/IME_KEY` with the decimal key code as the arg string. The
  returned first line is the action digit: `0` not IME business,
  `1` preedit strip updated, `2` commit (insert text), `3` commit +
  caller handles key; **action 4** is the local classification of
  service failure / malformed protocol - the key is swallowed, never
  leaked into the file (postmortem disaster 6).
- Key map (nano face): 0x80..0x83 arrows, 0x84/0x01 Home, 0x85/0x05
  End, 0x89 Delete, ENTER split, ^K cut, ^R copy, ^U paste, ^C
  position, ^G help, ^O save, ^X exit (dirty prompt), 0x20..0x7E
  insert.
- `unano_save` opens with flags 22 (WRONLY|CREAT|TRUNC); `unano_load`
  reads via a 4096-byte static buffer and tracks `dropped_lines` /
  `long_line` for the truncation guard above.
