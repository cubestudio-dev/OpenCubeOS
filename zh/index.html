WP-10c-selfhost · Apache 2.0

Open Cube OS
开源 x86_64 L0 内核

它不是“一个能日常使用的系统”，而是“一个能被扩展成任何东西的内核”。价值不在自带什么，而在向上层暴露的接口：L0 = 完整内核，L1 = 上层扩展，L0 不内置任何 L1。WP-10c 声卡驱动（Intel HDA / AC'97 / SB16 / ES1370 / virtio-snd / USB 音频，真 DMA 真中断）已落地，第 ⑨ 条用户角度可用性审计完成（TRY-IT / UPDATE-HOWTO 指南、一键 A/B 磁盘、mkfs/fsck 修复、play/volume 反馈），系统内自动更新、网卡/存储驱动与安全传输保持主流化：SSH（curve25519、主机密钥验证、公钥认证）、TLS 1.3 / TLS 1.2（CA 链验证）、crypto 核心。

WP-10c

系统内自动更新（A/B 分区）

Windows-Update 式更新：内核自带 gzip/DEFLATE + ustar 解包与流式 SHA256 校验，A/B 双分区安装、boot 标志自动回滚、update --local 离线更新；real_update_test 实测下载-安装-重启进入 slot B-回滚全链路。

WP-10u

网卡驱动（九族）

e1000e / igb / ixgbe / RTL8139 / RTL8168 / RTL8125 / RTL810x / BCM57xx 及 3c59x、nForce、AR81xx、Yukon 识别与驱动：nic_register/send/recv/link_status/get_mac 扩展接口；e1000e、igb、RTL8139 在 QEMU 实测 DHCP/ping/HTTPS 全链路。

WP-10b

AHCI SATA

SATA 硬盘/SSD 驱动：精确类别 0x010601 枚举、命令列表/H2D FIS、48 位 LBA DMA 读写、FLUSH CACHE，多控制器多端口。

WP-10a

NVMe SSD

NVMe 驱动：管理队列对 + 双 I/O 队列对轮询、Identify、Read/Write/Flush，doorbell 提交完成。

WP-10a

ATA Bus-Master DMA

经典 IDE 走 PCI BMDMA（BAR4 + PRDT）真 DMA 传输，PIO 路径保留为回退；自测含 DMA vs PIO 计时对比。

WP-10a

virtio-blk

QEMU virtio 磁盘：容量读取修复（此前为 0）、virtqueue 请求/应答、读写刷全链路。

WP-10a

FAT32 全设备挂载

FAT32 从直连 ATA 迁移到 blk 层：hda/sda/vda/nvme0 四类驱动均可 mkfs + 挂载 + 文件往返；MBR + GPT 分区解析。

WP-10a

TLS 1.3 / TLS 1.2

TLS 1.3（X25519 + AES-128-GCM，ChaCha20-Poly1305 套件）+ TLS 1.2 ECDHE-GCM 回退；X.509 CA 链验证（内嵌公共根），验证失败即握手失败。
