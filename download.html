Two channels: the 3.0.0 development preview (the L0/L1 world of WP06g3) and the 2.2.0 stable release. Every asset's SHA256 is listed - verify what you download: sha256sum <file>.

3.0.0-WP06g3 - development preview

The current 3.0.0 milestone: OCBL → OCOS → the ring-3 ush shell (285 commands), plus the OCSE install environment (the 9-step GUI install wizard + OCSECL, en/zh). Boot either ISO in QEMU (-cdrom) or write it to USB. See the WP06g3 release page.

Install medium - OCSE

ocse-3.0.0-WP06g3.iso

The OCSE install environment (4.8 MiB): the 9-step GUI install wizard and OCSECL, en/zh - every wizard mutation is a real OCSECL command. Installs OCBL + OCOS onto a disk that then boots to ush.

Size: -
-
⬇️ Download ISO

Try it in one command

$ qemu-system-x86_64 -m 512 -cdrom opencube-3.0.0-WP06g3.iso \ -netdev user,id=n1 -device e1000,netdev=n1

512 MiB of RAM is comfortable; the ISO is self-contained. The installed-disk path: boot ocse, run the wizard, reboot - OCBL takes over.
